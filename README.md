# FitCare

Тренер в телефоне: камера смотрит, как ты приседаешь, приложение считает повторы, ловит ошибки техники, а тренер комментирует с дружеским сарказмом. Вокруг — трекер здоровых привычек с геймификацией. MVP для хакатона.

## Разделы

| Вкладка | Что внутри |
| --- | --- |
| Сегодня | Тренер с фразой дня, винстрик (неделя, отсчёт до сгорания), сводка: вода, шаги, привычки, уровень |
| Тренировки | **Присед с ИИ-камерой** (ядро продукта) + таймерные тренировки: ходьба, кардио, растяжка, мобильность, с фильтром и избранным |
| Привычки | Вода, шаги, 12 привычек, 3 челленджа дня, настроение, сон, календарь 30 дней |
| Разум | Дыхание 4-4-6-4, медитация, дневник с поиском, викторина (14 вопросов), совет дня, идея для еды |
| Профиль | Уровень и XP, 12 значков, отчёт за неделю, тон и пол тренера, цель шагов, экспорт/импорт, сброс |

XP начисляется за подход приседаний (+15 и +2 за каждый чистый повтор), привычки, норму воды и шагов, челленджи, дневник, дыхание, медитацию и викторину. 100 XP — новый уровень.

Трекер привычек перенесён из отдельного прототипа FitCare (vanilla JS, узбекский) и переведён на русский. Не перенесены: локальная регистрация с паролем (по ТЗ регистрации нет), ввод ключа Claude в браузере (ключ живёт только на сервере, ИИ идёт через `/api/coach`) и калькулятор через `Function()`.

**Демо-сценарий:** онбординг → тренировка с камерой (присед) → разбор техники от ИИ-тренера.

## Запуск локально

```bash
npm install
cp .env.example .env   # вписать ANTHROPIC_API_KEY (необязательно — без него работают запасные фразы)
npm run dev            # https://localhost:5173 и https://<IP-компьютера>:5173
```

`npm run dev` поднимает и фронтенд, и `/api/coach` (функция запускается внутри Vite, Vercel CLI не нужен).

### Камера с телефона и с Windows

Браузеры дают камеру **только по HTTPS** (или на `localhost` того же компьютера). Если открыть `http://192.168.x.x:5173`, камера заблокирована — приложение покажет «Камера работает только по HTTPS».

- `npm run dev` поэтому запускается по HTTPS с самоподписанным сертификатом. На устройстве откройте `https://<IP-компьютера>:5173` и один раз подтвердите предупреждение: Chrome/Edge — «Дополнительно → Перейти на сайт», Safari на iPhone — «Подробнее → Посетить веб-сайт».
- Для выступления надёжнее ссылка Vercel: там настоящий HTTPS без предупреждений.
- `npm run dev:http` — старый режим без HTTPS (только для localhost).

Если камера всё равно не включается, приложение пишет причину: доступ запрещён в настройках, камера не найдена или занята другой программой (Zoom, Teams).

## Переменные окружения

| Переменная | Где | Зачем |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | только сервер (`api/coach.ts`) | Ключ Claude API. Во фронтенд не попадает. |
| `COACH_MODEL` | только сервер | Модель тренера, по умолчанию `claude-haiku-5-5` |

Без ключа, без интернета или при таймауте (8 сек) приложение молча берёт фразы из локального банка (`src/coach/fallbackPhrases.ts`).

## Флаги в URL

| Флаг | Что делает |
| --- | --- |
| `?demo=1` | Тренировка сразу на демо-видео `public/demo/squat-demo.mp4` вместо камеры (если онбординг пройден) |
| `?debug=1` | Поверх видео: fps, состояние автомата, сторона, углы колена и корпуса, подъём пятки |
| `?reset=1` | Стереть все локальные данные и начать с онбординга |

Флаги запоминаются до закрытия вкладки. Кнопка «Демо-видео» есть и на экране подготовки.

## Как это устроено

- **Распознавание позы** — `@mediapipe/tasks-vision` PoseLandmarker (lite, VIDEO), только в браузере. Модель и wasm лежат в `public/mediapipe/` (wasm копируется из `node_modules` перед `dev`/`build`). Кадры никуда не отправляются.
- **Анализ приседа** — `src/pose/squatAnalyzer.ts`. Все пороги в `SQUAT_CONFIG`. Пользователь стоит боком; считаются угол колена (EMA 0.4), наклон корпуса, подъём пятки. `heels_up` выключена по умолчанию (шумит) — включить `heelsUpEnabled: true`.
- **Тренер** — PNG-позы `public/trainers/{male,female}/{hello,idle,good,error,again}.png`. Имена — `TRAINERS.*.name` в `src/config/trainers.ts`. Если картинки нет, показывается заглушка.
- **ИИ** — `api/coach.ts` (Vercel function, `@anthropic-ai/sdk`), режимы `summary`, `chat`, `daily`. В модель уходят только имя, пол, цель и тон — вес, рост и возраст не отправляются. Во время тренировки ИИ не вызывается.
- **Данные** — только localStorage (Zustand persist). Регистрации нет.
- **Тема** — тёмно-серая с кислотно-лаймовым акцентом; все цвета в `src/config/tokens.ts`.
- **Винстрик (как в Duolingo)** — огонь со счётчиком, неделя, рекорд. Если вчера тренировка была, а сегодня ещё нет — красный баннер с обратным отсчётом до полуночи и давление от тренера. Пропуск дня сжигает стрик — при следующем входе экран «Стрик сгорел». Продление стрика празднуется на экране результата. Попытка закончить подход раньше 5 повторов — диалог «уже сдаёшься?» с выходом «Что-то болит» без давления.
- **Анимации тренеров** — спрайт-листы 12 кадров из Blender (`public/trainers/*/*.sprite.webp`), рендер: `scripts/blender/render_trainer_sprites.py`. PNG-позы остаются запасным вариантом.

## Ассеты из Blender

Тренеры и запасное демо-видео рендерятся из `Body Mechanics Rigs.blend` (персонажи Jack и Jill):

```bash
BLENDER=/Applications/Blender.app/Contents/MacOS/Blender
$BLENDER -b --disable-autoexec "Body Mechanics Rigs.blend" --python scripts/blender/render_trainers.py -- public/trainers
$BLENDER -b --disable-autoexec "Body Mechanics Rigs.blend" --python scripts/blender/render_squat_demo.py -- public/demo/squat-demo.mp4 male
```

Позы задаются углами костей в `POSES` внутри `render_trainers.py`.

> `public/demo/squat-demo.mp4` сейчас — рендер манекена. MediaPipe распознаёт его хуже человека (занижает глубину), поэтому для выступления замените его на настоящую запись: 10–15 сек, боком, во весь рост, 2–3 м, пара приседов с ошибками.
